## Open Ports Identified

| Port | Service | Description |
|------|--------|------------|
| 135 | MS RPC | Windows system communication service |
| 445 | SMB | File and printer sharing service |
| 1521 | Oracle DB | Oracle database listener |
| 3306 | MySQL | MySQL database service |
| 5500 | Oracle EM | Oracle Enterprise Manager |
| 49165 | Dynamic | Windows dynamic port |
| 61900 | Dynamic | Ephemeral service port |

## Security Significance
Open ports indicate active services on the system. Database and file-sharing ports must be properly secured to prevent unauthorized access.
